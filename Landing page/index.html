A student management system is a simple web development project used to store and manage student information. It allows users to add student details, view records, search students and manage their information easily. This project is created using basic HTML, CSS and JavaScript.

ABOUT PROJECT

STUDENT MANAGEMENT

This project helps in maintaining basic student records. The user can enter a student's name, ID, email, course and gender. The records can then be viewed and searched from the student list.
